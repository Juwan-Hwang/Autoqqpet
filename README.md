| --- | --- |
| 自动照顾 | 体力 / 清洁低于阈值就喂食、洗澡；饼干香皂用完**自动补货**（花游戏金币） |
| **最优调度**（v2.0.0 新增，默认） | 不再凭固定规则挑下一件事：把今天剩下的账按**实时目录**算一遍全天最优安排（疲劳按官方三档分段折算、补给按单价计入、冒险按期望值并有每日上限），只走第一步、每趟重算。目标三选一：**金币优先 / 工分优先 / 属性优先**；工分挡带净亏刹车（折算后收入盖不住补给耗费的工不排），属性挡可设学习停课线 |

| 好友互动 | 任务中顺带 PK（只挑比自己弱一截的，比例可调）、访问、踩踩；每日上限 + 黑名单 / 白名单；**输一次的对手自动进黑名单** |

## 安装

0. **先校验**（建议）：下载后核对 SHA-256 与发布页写明的值一致，不一致就不要装。
   文件名应为 `autoqqpet-v<版本号>.apk`（两处下载页的资产名与校验和相同）。
   ```powershell
   certutil -hashfile autoqqpet-v2.0.0.apk SHA256   # Windows
   shasum -a 256 autoqqpet-v2.0.0.apk                # macOS / Linux
   ```
1. 从上面任一下载页取最新 APK 并安装。升级直接覆盖安装即可（v2.0.0 的 versionCode 为 24，可直接覆盖旧版），设置与当日进度不会丢。
2. 打开 LSPosed / Vector → 启用 `Autoqqpet` → **作用域勾选 QQ**。
3. **重启 QQ**（必须：模块只在 QQ 启动时加载）。
4. 打开 Autoqqpet，**允许通知权限**。许可协议有更新，从旧版升级的也要重新滚到文末确认一次。
5. 省电设置（很关键，否则会被系统冻结）：设置 → 电池 → QQ → 允许后台活动 / 不受限；并在最近任务里锁定 QQ。应用内「设置 → 后台运行」能直接看本模块和 QQ 的电池限制状态，点一下就跳系统设置。
6. 回到 Autoqqpet → 选好「怎么干活」与目标 → 点「▶ 开启自动托管（含强保活）」。
   （不需要任何“悬浮窗/显示在其他应用上层”权限：本模块**从不把 QQ 拉到前台**，也不会屏幕上多任何东西。）

## 界面怎么用

**首次打开会依次出现两步**（只一次）：

1. **免费与风险声明** —— 点「我知道了」继续，点「查看项目主页」先到 GitHub 看仓库。
2. **最终用户许可协议** —— 必须把全文**滚到文末**才能勾选「我已阅读并同意」，再点「同意并继续」才能进入应用。
   不同意就点「不同意（退出应用）」，应用直接退出。
   协议文本改版后会重新要求确认。

### 主页

**「此刻」卡**：一只会呼吸、会眨眼的团子，外圈是任务进度环（学习、打工、冒险、照顾各一色），
下面一行是服务器给的叙事——宠物此刻在干什么、还剩多久，一目了然。
再往下是**属性与战力**（力量、智力、魅力，每小时读一次服务器数值）、**今日经验**、
**今天**（只统计已经完成的学习/打工/冒险，进行中的不算）和**今日收益**
（金币净变化、一整天的金币曲线、服务器实发的奖励；每天零点归档成「昨天」报告卡）。
主页的提醒条会告诉你下一步该做什么，每条都能划掉，划掉后同一件事不会再弹。

**怎么干活**（五选一，改了立刻生效、不用重启 QQ）
- **最优调度（新装默认）**：把今天剩下的账按实时目录算一遍全天最优安排，只走第一步、做完一趟重新算。
  下面选目标：**金币优先**（攒钱）/ **工分优先**（攒工分，期末金币不能比早上少；折算后收入盖不住
  补给耗费的工不排）/ **属性优先**（练属性，同上保底；可再设学习停课线，默认进一折时段就停课）。
  选了工分优先时还能指定职业（去哪打工），不指定就是同职业里挑单位时间工分最高的。
- **学习优先**：旧逻辑，疲惫后转冒险。
- **工作优先**：旧逻辑，疲惫后转冒险。
- **只冒险**：不学习、不打工，只刷冒险；可固定刷哪一个（自动 / 附近走走 45 秒 / 诗和远方 2 小时）。
- **自定义排班**：自己定先后顺序与例外规则（进设置页编辑）。

**托管开关** + **更多**（设置页、火花页、项目主页、协议全文）。

### 设置页

设置按组分开，一个设置只出现一处；设置搜索支持**拼音首字母**（输 hh 搜「火花」）。

**干活**：干活方式（上面五挡）、学习停课线、排班入口、每天最多冒险、任务间隔（每件任务结束后歇几秒再开下一件，默认 10 秒）、学习/打工鼓励次数（0–10，默认 1）。

**打工方向 —— 在哪里打工**：**自动（哪个职业划算去哪个）**或你点名的某个职业。
选项从服务器现读，**只列出你这个账号解得开的职业**（有人八个、有人更少）。
**时长档位不让人选**：四档（10 分钟 / 45 分钟 / 2 小时 / 4 小时）每轮全部读回来，按【当时】的实时数字算净收益取最划算的那个。
因为宠物疲劳、体力不足时，服务器下发的收益与可做情况会一起变：某一刻算出来只有短档不亏，写死“哪档最划算”就会去开一个亏本的档。
若几个职业算出来完全相等，界面**不标“最佳”**，只告诉你并列。

**被好友雇走**：**自动召回默认开**——靠服务器的「雇佣了」通知确认确实被雇走（不是你自己手动开的打工），
进度到 71%（这段区间的分成归我们拿大头）自动召回；可改成立刻召回，或关掉召回只留提醒（提醒默认关、召回开着时不提醒）。
另有「检查是否被雇佣」：服务器不推送这类通知，只能每 10 分钟拉一次确认。

**后台运行 —— QQ 被杀之后能不能自己爬起来**：不用动也会自己爬起来。看门狗只用**静默手段**：
查 QQ 导出的 provider 把**进程**拽回来（不弹任何界面、窗口焦点不变）、补发指令。
**它永远不会把 QQ 拉到前台抢你的屏幕**；真的需要你动手时只挂一条通知，点不点由你。
这一组还能看本模块与 QQ 的电池限制状态、QQ 的精确闹钟状态，以及可选的「强力唤醒（闹钟级）」
（唤醒用系统闹钟级别、省电模式下也准点，代价是状态栏常驻一个闹钟图标）。

**火花**：每天自动踩好友的开关与节奏、火花黑名单、两种提醒（实验）。好友的火花天数与状态在主页的火花页里看。

**每日白捡**：每日签到领食物、信箱一键领取（实验）、自动领福袋（含自己名下的）与每日上限。

**帮好友照顾 / 好友名单**：代喂代洗、一键照顾、代喂后通知对方；黑名单与白名单按昵称打勾多选，
名册从服务器现抓，不需要先跟谁打过才能拉黑。PK 按服务器给的真实战力挑对手（只挑比自己弱一截的，比例可调），
**输掉的对手会自动进黑名单**。

**排班（设置页 → 编辑排班）**：开关、跑完一轮后（回到第一步 / 停下）、步骤列表（长按或拖手柄排序）、例外规则。
步骤按“做什么 → 哪一条 → 做到几次/多久”四步设完，取消不改动；不指定就是每轮现算最划算的那条。
某一步做不了时按规则处理，没写规则就跳到下一步，不会空转。**排班严格按你排的顺序和次数执行**，
疲劳不会半路把它拦下；想“累了先停”就在例外规则里写一条「今日已判疲劳」规则。

**外观**：跟随系统 / 浅色 / 深色，6 种主题色（默认海蓝），每个主题色整套换背景；选完立即生效，不需要重启应用。

**诊断与反馈**：运行诊断一键体检 10 项（LSPosed 是否生效、心跳、设置是否已生效等），总评把
「暂时判断不了」单独计数，不会冒充全部通过；无法自动判断的项目可以点按钮手动确认已设置。
反馈问题可带诊断快照，QQ 号、宠物 ID、好友昵称自动打码。

**关于** —— 版本、协议全文、项目主页与 Issues 入口。

> 疲劳怎么算，分两种情况：
> - **最优调度**：按官方三档——学工累计 8 小时内收益全额、8–12 小时 25%、12 小时后 10%，
>   一件跨档的任务按分钟分段加权，整份全天安排都按这个口径算账。它不是设置项，是排进计划里的。
> - **旧逻辑（学习优先 / 工作优先）**：看**收益本身**——每轮读到的课程/岗位预计收益与当天峰值比，
>   同一条目录项低了 5% 以上就只剔掉那一档（没降的短档照做），全部档位都降了才整天只冒险；
>   峰值每天重置，第二天自动重取基准。判定时会说清是哪一条降了多少
>   （例：`岗「街角占卜摊」 本次 60.0，今日最高 84.0（已降 28%）`）。

## 常见问题

**通知栏显示「⚠️ 可能已停止」怎么办？**
它只在“心跳断了（QQ 被杀/被冻结）”或“循环没排上下一次唤醒（卡住）”时出现，且自己会在 90 秒内重试接回。
点通知可直接拉起 QQ 并续跑。如果反复出现，通常是省电策略把 QQ 冻住了 —— 回到上面第 5 步设置白名单，并确认框架作用域勾了 QQ。

**会不会有悬浮窗挡屏幕？会不会突然把 QQ 弹到我面前？**
两者都不会。屏幕上不会出现任何小窗口、按钮、遮罩或动画，也不拦点击（本应用无悬浮窗绘制代码）；
而“把 QQ 拉到前台”这条路径已于 v1.1.1 **彻底删除**，连为它而存在的可选权限`SYSTEM_ALERT_WINDOW`
也不再申请。后台恢复靠的是静默拉进程（只唤起进程、界面不出现、你手里的 app 仍是焦点）。
代价是极端情况下（系统连静默唤进程都不放行）需要你点一下通知，而不是它自动恢复 —— 这是故意选的取舍：**不打扰优先于自动**。

**怎么确认它真的在干活？**
看通知栏文本；或连上 adb：`adb logcat | findstr Autoqqpet`（Windows）/ `adb logcat | grep Autoqqpet`（macOS/Linux）。

**中途想换目标属性或换模式？**
直接在界面点，下一轮决策立刻生效，不用重启 QQ。

**升级 APK 会丢进度吗？**
不会。设置与当日进度存在本机，覆盖安装不清除。

**怎么彻底停用？**
先点「⏹ 停止自动托管」，再到框架里关闭模块开关（或直接卸载 APK）。

## 已知限制（诚实清单）

- **QQ 版本敏感**：宠物模块内部会改混淆类名（发包入口：9.3.65 是 `qqpet.delegate.l`、9.3.70 是 `qqpet.delegate.m`、
  9.3.75 干脆改成了可读名 `qqpet.delegate.QQPetPbDelegate`）。从 v0.1.5 起不再写死类名：**按方法签名自动发现入口**
  并自动选对可用的运行时环境；v1.0.1 起候选类名不再只试单字母（旧版的命中顺序不变，9.3.65/9.3.70 行为一致）。
  若下次更新改得更彻底，通知栏会直接提示“QQ 里没有本模块的心跳”而不是默默不干活，届时再看 Issues 是否有适配版。
  建议：**关掉手机 QQ 的自动更新**，避免它在夜里把环境换掉。
- **QQ 升级后可能要你动一下手**：真机碰到过“QQ 装完新版后，注入框架对这个新包直接不再注入”（不是模块本身的问题）。
  现象就是通知栏报“QQ 里没有本模块的心跳”；在框架里把本模块**禁用再启用**（或重新勾一次作用域），
  再彻底关掉 QQ 重开即可恢复。
- **属性与战力是小时级读数**：三属性总量改为每小时读一次服务器数值显示（战力为三者之和），不是逐秒实时；
  两次读取之间刚结算的任务不会立刻反映在数字上。
- **被雇佣的确认靠轮询**：服务器不推送「雇佣了」通知，模块每 10 分钟拉一次确认，所以自动召回的
  触发可能比进度到 71% 的时刻晚几分钟；没被召回也不会出错，到点照样正常结算。

## 隐私

- 本 APK **没有申请网络权限**：不联网、不采集、不上传任何数据；没有统计埋点、没有广告 SDK、没有崩溃上报、没有自动更新检查。
- 它的功能是在你自己的手机 QQ 进程内调用 QQ 自身的宠物接口，因此会产生**由 QQ 发出、发往腾讯服务器**的宠物协议请求 —— 这就是工具本身的工作方式，除此之外没有任何网络行为。
- 不读取聊天内容。设置、当日进度、日志全部只存在本机应用私有目录。
  v1.0.1 起这两份配置的**主存在本模块自己的目录**（只有卸载本模块才会清），QQ 数据目录里只是一份工作副本；
  所以 **QQ 重装或清数据后不会再连累你的设置**，QQ 启动时会自动从主存恢复（设置页与日志会写明当前用的是哪份）。
- 设置页的「反馈问题」不会替你上传任何东西：它只把运行状态与日志填进你自己浏览器里的新建 issue 页面，
  完整日志只复制到剪贴板（粘不粘由你定）。日志里的 QQ 号、宠物 ID、好友昵称已自动打码。
- 清单里的“查询已安装应用”权限只用于确认 QQ 存在并把它拉起，不读取其他应用数据。
- **不申请“显示在其他应用上层”**：v1.1.1 起已删掉该权限声明（它唯一的用途就是后台把 QQ 拉到前台，
  而这条路径已经为了“永不打扰用户”移除了）。以前给过的用户升级后该授权会自动失效，不影响使用。
- 首次打开会弹出一段免费与风险声明，并提供跳转项目主页的按钮；界面上也可随时重看。

## 安全与加固

- **发行版不含抓包功能**：开发自用的抓包/侦察工具只保留在开发调试包里，发行版里连相关代码都不存在
  （不是藏起来，是根本不编译进去）。
- 发行版经过多层反逆向加固（协议命令加密存放、核心校验在原生层并与签名绑定，被重新打包换签名后发不出包）；
  独立验收（静态分析与通用离线模拟路线）确认无法轻易逆向。
