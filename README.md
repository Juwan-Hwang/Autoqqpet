## 为什么用它

- **不需要电脑、模拟器或第二台手机。** 它是一个 LSPosed 模块，就跑在你手机里的 QQ 中。
- **装好就不用管。** 照顾、学习、打工、冒险一条龙；QQ 被系统杀掉也能静默接回。
- **从不打扰你。** 不会把 QQ 弹到你面前，没有悬浮窗；真需要你动手时，只发一条通知。
- **只在本机。** 没有网络权限，不上传任何东西。

## 它能做什么

| | |
| --- | --- |
| **照顾** | 体力、清洁低了就喂食、洗澡；饼干和香皂用完自动补货（花游戏金币）。 |
| **最优调度**（默认） | 把今天剩下的账按实时目录算一遍全天最优安排：疲劳按官方三档分段折算、补给按单价计入、冒险按期望值，只走第一步、每趟重算。目标三选一：金币优先 / 工分优先 / 属性优先；工分挡带净亏刹车，属性挡可设学习停课线。 |
| **学习** | 按你要练的属性（力量 / 智力 / 魅力）挑当下最划算的课，一节接一节，到期自动结算。 |
| **打工** | 自动选最划算的岗位与时长档；也可以指定只去某个职业。列表直接读自你的账号，只列出你解得开的职业。 |
| **冒险** | 学工都累了才去冒险；也可以选「只冒险」一直刷短冒险。冒险金币到顶当天自动停派（排班不受影响）。 |
| **五种干活方式** | 最优调度（新装默认）· 学习优先 · 打工优先 · 只冒险 · 排班。学习优先 / 打工优先是旧逻辑，学工疲惫后转冒险。 |
| **排班** | 自己定顺序：每一步“做什么、做哪一条、做几次或做多久”，做完进下一步；可设例外规则，比如“体力低于 30 时，先照顾”。 |
| **学累了自动收手** | 不靠猜：读服务器发下来的结算明细，实收比预期少了，才判定这一档今天干累了，第二天自动重来。 |
| **算得清账** | 今天净赚多少金币、一整天的金币曲线、服务器实发了哪些奖励，主页一眼看完；每天零点归档成「昨天」报告。 |
| **雇好友一起干**（默认关） | 250 金币只在第一次雇时扣，当天复用不再花钱；只在预期多赚够 250 的长单上新雇；开工前先问服务器对方能不能雇。 |
| **被雇走自动召回**（默认开） | 确认被好友雇走（服务器通知里有“雇佣了”）后，进度到 71% 叫回来，拿满基础工资和 75% 分成；可改成“立刻召回”。 |
| **属性与经验** | 主页显示力量、智力、魅力、战力和今日经验；PK 按真实战力只挑弱一截的对手，胜负按服务器结算称号判断。 |
| **火花** | 你定每天踩谁、谁永远不踩；每天各踩一次不断线，快断了提醒你。可选回踩（默认关）。 |
| **每日白捡** | 签到领食物（默认开）、信箱一键领取（实验，默认开）、福袋（默认关，自己名下的也能领）。 |
| **照顾好友**（默认关） | 好友饿了脏了，用你的饼干香皂帮一把；或用一键照顾。都有阈值和每日上限。 |
| **好友互动** | 任务间隙 PK（只挑比自己弱的，输一次永久拉黑）、访问、踩踩，带黑名单与白名单和每日上限。 |
| **实验功能** | 个别请求格式是按回包推断的功能，界面里标着「实验」。 |
| **保活** | 前台服务 + 看门狗 + 开机自启；QQ 被杀先静默唤起进程，不弹任何界面。 |
| **看得见** | 主页实时显示宠物在做什么、还剩多久、今天做了什么；通知栏随时可看。 |
| **不丢设置** | 设置与当日进度存放在模块自己的目录里，QQ 重装或清数据也不会带走。 |

## 安装

**0. 先校验（建议）。** 下载后核对 SHA-256 与发布页写明的值一致；不一致就不要装。文件名形如 `autoqqpet-v<版本号>.apk`，两处下载页是同一个签名文件，校验和相同。

```
certutil -hashfile autoqqpet-v<版本号>.apk SHA256   # Windows
shasum -a 256 autoqqpet-v<版本号>.apk                # macOS / Linux
```

1. 从 [项目主页 Releases](https://github.com/Juwan-Hwang/Autoqqpet/releases/latest) 下载最新 APK 并安装。在 LSPosed / Vector 商店里点“下载”会指向 [模块仓库 Releases](https://github.com/Xposed-Modules-Repo/com.juwanh.autoqqpet/releases/latest)，两者是同一个文件。升级直接覆盖安装，设置与当日进度都在。
2. 打开 LSPosed / Vector，启用 **Autoqqpet**，作用域勾选 **QQ**。
3. **彻底关掉 QQ 再打开**（模块只在 QQ 启动时加载）。
4. 打开 Autoqqpet，读完首启说明与许可协议，允许通知。
5. **省电设置很关键**：系统设置 → 电池 → QQ → 不受限制 / 允许后台活动；并在最近任务里锁定 QQ。App 里的「运行诊断」会帮你逐项核对。
6. 回到主页，选好干活方式与要练的属性，打开 **托管**。

不需要“悬浮窗 / 显示在其他应用上层”权限。

## 第一次打开

只出现一次（协议文本更新后会请你重新确认）：

1. **开始之前**：免费、风险自负、与腾讯无关 —— 三件事说清楚再往下。
2. **许可协议**：读到最后才能勾选“我已阅读并同意”，勾选后才能继续。不同意就退出，什么也不会保存。

## 界面一览

**主页「此刻」** —— 打开就知道它在干什么。
- **舞台**：团子、进度环与倒计时。颜色告诉你它在做什么：靛色学习、琥珀打工、青色冒险、玫红照顾。
- **心跳行**：最近一次心跳、下次醒来的时间；点「诊断」直达体检。
- **此刻叙事**：服务器说宠物正在做什么，就原样写在倒计时下面。
- **提醒**：模块没启用、该召回了、照顾被拒、学费不够、信箱可领、QQ 失联时才出现，并告诉你下一步怎么做。
- **托管开关**，以及 **怎么干活**（最优调度 / 学习优先 / 打工优先 / 只冒险 / 排班）和 **练什么**（力量 / 智力 / 魅力）。
- **属性与经验**：力量、智力、魅力、战力，今日经验进度与各项每日任务。
- **今日收益**：金币净变化（滚动数字）、会自己画出来的金币曲线、服务器实发的奖励。
- **今天**：学习、打工、冒险各几次，学工与冒险的时长构成。
- **时间线**：今天做过的每一件事。
- **昨天**：一句话总结加四格数字，PK、雇佣、帮好友、福袋另起一行。

**设置** —— 每一项都写清楚开或关会发生什么。
- 干活：干活方式（五挡）、去哪打工、刷新打工目录、排班、学习停课线、每天最多冒险几次、任务间隔、学习/打工鼓励次数、实时叙事、读结算明细、用实收校准收益。
- 金币与雇佣：金币底线、开工时雇好友与每日上限、被雇走自动召回与召回时机。花金币的开关打开前都会先说清楚。
- 照顾与补给：体力和清洁低于多少就照顾、用完自动补货。
- 每日白捡：签到领食物、信箱一键领取与提醒、福袋。
- 好友：火花（每天踩谁/不踩谁、回踩、快断提醒）、任务间隙 PK 与上限和对手强弱比例、替好友喂食洗澡（可选喂完告诉对方）、一键照顾、黑名单、白名单、刷新好友列表。
- 提醒与报告：被雇佣时提醒、检查是否被雇佣、每日报告。
- 外观：跟随系统 / 浅色 / 深色；Android 12+ 可跟随壁纸取色；减少动效。

**排班** —— 按住把手拖动排序；轻点一步就能改；规则读起来是一句话。只有最后一步可以“一直循环”。

**运行诊断** —— 模块、QQ、心跳、唤醒计划、通知、电池优化逐项体检；无法自动判断的项（如 QQ 的后台限制）可点按钮手动确认。一键采集运行快照、复制全文，或带着快照去 GitHub 反馈。

## 常见问题

**通知栏提示“可能已停止”怎么办？**
只在心跳断了（QQ 被杀或被冻结）或循环没排上下一次唤醒时出现，它会自己尝试接回。反复出现多半是省电策略冻结了 QQ：按「安装」第 5 步设置，并确认作用域勾了 QQ。

**会不会突然把 QQ 弹到我面前？会不会有悬浮窗？**
都不会。后台恢复只静默唤起进程，你手里的应用始终在前台。极少数情况下系统连静默唤起都不允许，这时它只发一条通知，点不点由你 —— 不打扰优先于自动。

**怎么确认它真的在干活？**
看主页的舞台与时间线，或通知栏。也可以连上 adb 看日志：`adb logcat | grep Autoqqpet`（Windows 用 `findstr`）。

**中途想换属性或干活方式？**
直接在主页点，下一轮立即生效，不用重启 QQ。

**升级会丢进度吗？**
不会。覆盖安装即可。

**怎么彻底停用？**
先在主页关掉托管，再到框架里关闭模块（或直接卸载）。

## 已知限制

- **对 QQ 版本敏感。** 宠物模块内部类名会随版本变化；本模块按方法签名自动寻找入口，不写死类名。若某次更新改得更彻底，通知栏与主页会直接提示“没有心跳”，而不是默默不干活。建议关掉手机 QQ 的自动更新。
- **QQ 升级后可能要你动一下手。** 真机遇到过框架对新安装的 QQ 不再注入：在框架里把本模块禁用再启用（或重新勾选作用域），再彻底重启 QQ 即可。
- **被雇佣是“拉”出来的。** 服务器不推送被雇佣消息，模块每 10 分钟看一次通知，所以发现可能晚几分钟（不影响 71% 召回）。

## 隐私

- **没有网络权限**：不联网、不采集、不上传；没有统计、广告 SDK、崩溃上报或自动更新检查。
- 它在你自己的 QQ 进程里调用 QQ 的宠物接口，因此会产生**由 QQ 发出、发往腾讯服务器**的宠物请求 —— 这就是它工作的方式，除此之外没有任何网络行为。
- 不读取聊天内容。设置、当日进度与日志只保存在本机。
- 「反馈」不会替你上传任何东西：它只把打过码的运行快照填进你自己浏览器里的新建 issue 页面，完整日志复制到剪贴板，粘不粘由你决定。QQ 号、宠物 ID、好友昵称会自动打码。
- “查询已安装应用”权限只用于确认 QQ 存在并把它拉起。
- 不申请“显示在其他应用上层”。
