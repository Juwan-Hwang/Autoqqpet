## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 自动照顾 | 体力 / 清洁低于阈值就喂食、洗澡；饼干香皂用完**自动补货**（花游戏金币） |
| 自动学习 | 按你选的目标属性自动挑最划算的课，一节接一节排课，到期自动结算 |
| 自动打工 | 遍历已解锁职业，按性价比选岗位；被职业门槛拒绝时自动换下一个职业 |
| **打工方向可选** | 下拉框列出你账号**实际解得开的全部职业**（每个职业四个时长档位都读得到），锁定只在哪一处打工；**时长档位不让人选**，每轮按服务器实时数字自动取最划算的那个 |
| **重复刷冒险** | 短冒险约 **48 秒一轮** 连续刷；也可以设成"当天学工满 N 小时后只去冒险" |
| 每日预算 | 学习 + 打工的每日时长上限：6 / 8 / 10 小时 / 不限 |
| 好友互动 | PK、访问、踩踩；带每日上限、白名单 / 黑名单、连续失败自动拉黑 |
| 被雇佣提醒 | 宠物被好友雇佣去干活时，进度一到 71%（这段区间的分成归我们拿大头）就弹通知，提醒你去 QQ 里手动点「召回」 |
| 强保活 | 前台服务 + 唤醒锁 + 看门狗（循环卡住自动接回；QQ 被杀先**静默唤醒**，不弹界面也不打扰你当前在用的应用）+ 开机自启 |
| 状态可见 | 通知栏实时显示"正在干什么 / 是否正常 / 多久前心跳 / 多久后下次唤醒" |
| 数据不外传 | 只走 QQ 自己的通信通道，不连任何第三方服务器，不上传任何数据 |

## 安装

0. **先校验**（建议）：下载后核对 SHA-256 与发布页写明的值一致，不一致就不要装。
   文件名应为 `autoqqpet-v<版本号>.apk`（两处下载页的资产名与校验和相同）。
   ```powershell
   certutil -hashfile autoqqpet-v0.1.5.apk SHA256   # Windows
   shasum -a 256 autoqqpet-v0.1.5.apk                # macOS / Linux
   ```
1. 从上面任一下载页取最新 APK 并安装（升级请**覆盖安装**，不会清空设置与当日进度）。
2. 打开 LSPosed / Vector → 启用 `Autoqqpet` → **作用域勾选 QQ**。
3. **重启 QQ**（必须：模块只在 QQ 启动时加载）。
4. 打开 Autoqqpet，**允许通知权限**。
5. 省电设置（很关键，否则会被系统冻结）：设置 → 电池 → QQ → 允许后台活动 / 不受限；并在最近任务里锁定 QQ。
6. 回到 Autoqqpet → 选好属性与模式 → 点「▶ 开启自动托管（含强保活）」。
7. **可选**：界面第 5 组→开启「前台兜底（显示在其他应用上层）」。 看门狗默认先**静默唤醒** QQ（不弹界面），
   只有少数唤不回来的情况才需要把 QQ 拉到前台，而这个开关就是给那一步用的；不给也完全可用。
   **这个开关不会带来任何悬浮窗**，见下面 FAQ。

## 界面怎么用

**首次打开会依次出现两步**（只一次）：

1. **免费与风险声明** —— 点「我知道了」继续，点「查看项目主页」先到 GitHub 看仓库。
2. **最终用户许可协议** —— 必须把全文**滚到文末**才能勾选「我已阅读并同意」，再点「同意并继续」才能进入应用。
   不同意就点「不同意（退出应用）」，应用直接退出。
   协议文本改版后会重新要求确认。

之后界面就是五组选择，每一项都写清了后果，**当前生效的那一项前面有 ✅**：

**1. 想让宠物练什么属性** —— 力量 / 智力 / 魅力。

**2. 让它怎么干活**（三选一）
- **学习优先（推荐）**：优先上最划算的课；学费不够、或当天学工已经满了，自动改去打工 / 冒险。
- **工作优先**：一有空就先打工（哪怕这一轮冒险算出来更划算），学习只在没活可干时补位。
- **只重复冒险**：像学习一样一条路跑到底，一直刷同一个短冒险，攒经验、道具与偶遇；不学习不打工。

**3. 在哪里打工** —— 一个下拉框：**自动（哪个职业划算去哪个）**，或你点名的某个职业。
选项是从服务器现读的，**只列出你这个账号解得开的职业**（有人八个、有人更少）；点「刷新打工目录」重新拉一次。
**打工的时长档位不让人选**：四档（10 分钟 / 45 分钟 / 2 小时 / 4 小时）每轮全部读回来，按【当时】的实时数字算净收益取最划算的那个。
因为宠物疲劳、体力不足时，服务器下发的收益与可做情况会一起变：某一刻算出来只有短档不亏，写死“哪档最划算”就会去开一个亏本的档。
若几个职业算出来完全相等（现在就是这样），界面**不会假模假式地标一个“最佳”**，只告诉你并列。

**4. 每天学习 + 打工的时长上限** —— 6 / 8 / 10 小时 / 不限。
满了之后当天不再学工，只继续冒险与照顾。（这个上限**不限制**冒险、喂食洗澡、好友照顾。）

**5. QQ 被系统杀掉后能不能自己爬起来** —— 不用动也会自己爬起来：看门狗先**静默唤进程**（不弹界面）；
未开启时多一个按钮「开启前台兜底（不会出现悬浮窗）」，点下去先弹说明再跳系统设置（仅用于静默唤不回来的偶尔情况）。

> 被好友雇佣的任务**不提供开关**：协议层无法代劳（服务端会拒绝我方的提前结算），
> 所以进度一到 71% 时会弹通知提醒你去 QQ 里手动点「召回」，详见「已知限制」。

底部：「▶ 开启自动托管」/「⏹ 停止自动托管」，以及「查看手机上实际生效的设置」、「项目主页 · 免费与风险声明」、「许可协议全文」（可随时重看协议）。

## 常见问题

**通知栏显示「⚠️ 可能已停止」怎么办？**
它只在“心跳断了（QQ 被杀/被冻结）”或“循环没排上下一次唤醒（卡住）”时出现，且自己会在 90 秒内重试接回。
点通知可直接拉起 QQ 并续跑。如果反复出现，通常是省电策略把 QQ 冻住了 —— 回到上面第 5 步设置白名单，并确认框架作用域勾了 QQ。

**开了「显示在其他应用上层」会不会有悬浮窗挡屏幕？**
不会。屏幕上不会出现任何小窗口、按钮、遮罩或动画，也不会拦截你的点击——本应用不含悬浮窗绘制代码。
它只用于一个少见的兜底场景：Android 14 起后台应用默认不能把其它应用拉回前台（被拦时还不报错），
而看门狗已经改成先**静默唤醒 QQ**（只拉起进程、不弹界面），只有连静默都唤不回来时才会试着拉到前台，
那个开关只是让这一步能成。平时不授予也完全不影响挂机，代价只是极端情况下需你点一下通知；随时可关掉。

**怎么确认它真的在干活？**
看通知栏文本；或连上 adb：`adb logcat | findstr Autoqqpet`（Windows）/ `adb logcat | grep Autoqqpet`（macOS/Linux）。

**中途想换目标属性或换模式？**
直接在界面点，下一轮决策立刻生效，不用重启 QQ。

**升级 APK 会丢进度吗？**
不会。设置与当日进度存在本机，覆盖安装不清除。

**怎么彻底停用？**
先点「⏹ 停止自动托管」，再到框架里关闭模块开关（或直接卸载 APK）。

## 已知限制（诚实清单）

- **QQ 版本敏感**：宠物模块内部会改混淆类名（例：发包入口在 9.3.65 是 `qqpet.delegate.l`、9.3.70 已是 `qqpet.delegate.m`）。
  从 v0.1.5 起不再写死类名：**按方法签名自动发现入口**，并自动选对可用的运行时环境，适应该类改名；
  若下次更新改得更彻底，通知栏会直接提示“QQ 里没有本模块的心跳”而不是默默不干活，届时再看 Issues 是否有适配版。
  建议：**关掉手机 QQ 的自动更新**，避免它在夜里把环境换掉。
- **三属性总量读不到**：游戏只在客户端本地保存，所以属性进度是**估算**，不是精确值。
- **被好友雇佣时不能自动召回**：真机实测服务端不接受我方发的提前结算包（错误码 135004），而 QQ 自己的“召回”按钮走的是我们抓不到的内部通道。
  现在改为**主动提醒**：进度一到 71%（这段区间的分成归我们拿大头）就会弹通知，请去 QQ 里手动点一下「召回」把宠物腾回来；
  没点也不会出错，到点照样正常结算，只是这段时间宠物干不了别的。

## 隐私

- 本 APK **没有申请网络权限**：不联网、不采集、不上传任何数据；没有统计埋点、没有广告 SDK、没有崩溃上报、没有自动更新检查。
- 它的功能是在你自己的手机 QQ 进程内调用 QQ 自身的宠物接口，因此会产生**由 QQ 发出、发往腾讯服务器**的宠物协议请求 —— 这就是工具本身的工作方式，除此之外没有任何网络行为。
- 不读取聊天内容。设置、当日进度、日志全部只存在本机应用私有目录。
- 清单里的“查询已安装应用”权限只用于确认 QQ 存在并把它拉起，不读取其他应用数据。
- 清单里的“显示在其他应用上层”是**可选**权限，且**不会真的画悬浮窗**：全工程没有悬浮窗绘制代码，
  只读一个开关状态作为“后台允许把 QQ 拉回前台”的系统豁免凭据；不给也能正常挂机，随时可关掉。
- 首次打开会弹出一段免费与风险声明，并提供跳转项目主页的按钮；界面上也可随时重看。
