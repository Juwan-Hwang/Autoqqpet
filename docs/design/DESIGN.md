# Autoqqpet 设计语言 · 「此刻」

> 一句话：**纸与墨做底，颜色只留给宠物此刻在做的事。**
> 界面不是控制面板，而是一扇看向宠物的窗：打开就知道它在干什么、还要多久、需不需要你。

本文是界面的唯一设计规范。代码里的令牌（`ui/theme/`）与本文一一对应；改一处，另一处同步改。

---

## 1. 原则

1. **状态先于控件**：主页第一屏是“它此刻在做什么”，控件排在后面。
2. **颜色即语义**：中性色承载一切结构；彩色只出现在任务（学习/打工/冒险/照顾）与健康状态（正常/留意/故障）上。一眼扫过去，颜色就是信息。
3. **动效只解释变化**：位置变了就滑过去，数值变了就滚过去，状态变了就淡过去。没有为动而动的装饰。
4. **一个概念一个叫法**：见第 8 节术语表。
5. **缺数据不是错误**：任何字段都可能还没到、或旧版本根本没有。缺的显示骨架或“—”，绝不崩、绝不编。
6. **合规流程不可省略**：免费与风险声明 → 协议读到底才可同意；协议文本一变就重新确认。

## 2. 色彩

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#F6F5F2` 暖纸 | `#0D0D11` | 页面底 |
| `surface` | `#FFFFFF` | `#16161C` | 卡片 |
| `surfaceRaised` | `#FFFFFF` | `#1D1D24` | 弹窗、底部面板 |
| `sunken` | `#EFEDE8` | `#101015` | 卡片里的槽（数值、输入框、分段选择底） |
| `line` / `lineStrong` | `#E6E3DC` / `#D6D2C9` | `#26262F` / `#34343F` | 发丝线 |
| `ink` | `#17161B` | `#F3F2F6` | 正文 |
| `inkMuted` | `#66636D` | `#A6A4AE` | 次要文字（对底色 ≥ 4.5:1） |
| `inkFaint` | `#A5A2AA` | `#5E5C66` | 仅装饰/禁用，不承载信息 |
| `accent` | `#4F46E5` 靛 | `#9D96FF` | 品牌：选中、主按钮、焦点 |
| `study` | `#4F46E5` | `#9D96FF` | 学习 |
| `work` | `#B35A00` | `#F2A646` | 打工 |
| `adventure` | `#0B7A6E` | `#3FD0BD` | 冒险 |
| `care` | `#C92A62` | `#FF7EAA` | 照顾 / 提醒 |
| `success` / `warning` / `danger` | `#12784A` / `#A65A00` / `#C0302B` | `#4CD992` / `#F5B547` / `#FF6E6A` | 健康状态 |

- 浅色主题所有承载文字的彩色在白底上 ≥ 4.5:1；深色主题提亮一档保证同等对比。
- **Material You（可选）**：设置 → 外观 →「跟随壁纸取色」（Android 12+）。只替换品牌色与表面色；**任务语义色不跟壁纸走**，含义不漂移。
- 阴影几乎不用：层级靠底色深浅 + 1dp 发丝线。唯一的投影是排班卡片被拖起时。

## 3. 字体

系统无衬线（中文落到系统黑体）+ 等宽；不外挂字体文件。**所有数字用等宽数字（`tnum`）**，倒计时与跳动的数字不左右抖。全部 `sp`，跟随系统字体缩放；容器只给最小高度。

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| `numeralXL` | 44 / 48 SemiBold tnum | 倒计时、步进器数字 |
| `hero` | 30 / 38 Bold | 页面大标题、“正在上课” |
| `headline` | 24 / 32 Bold | 面板标题 |
| `numeral` | 24 / 28 SemiBold tnum | 数值磁贴 |
| `title` | 17 / 24 SemiBold | 卡片标题、顶栏 |
| `bodyStrong` / `body` | 15 / 22–23 | 正文 |
| `caption` | 13 / 19 | 说明、后果 |
| `label` | 13 / 18 Medium tnum | 值、时间、胶囊 |
| `micro` | 11.5 / 16 SemiBold +8% 字距 | 分组标题 |
| `mono` | 12 / 18 等宽 | 诊断全文 |

## 4. 间距与圆角

- 4pt 网格：`2 4 8 12 16 20 24 32 40`；页面左右留白固定 **20dp**；内容最大宽度 **600dp**（平板/横屏居中）。
- 可点区域 ≥ **48dp**；列表行 ≥ 56dp。
- 圆角随容器变大：`8 → 12 → 16 → 22（卡片）→ 28（舞台/弹窗）→ 32（底部面板）`；嵌套时内圆角 = 外圆角 − 内边距。

## 5. 动效

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| 强调减速 `Emphasized` | `cubic-bezier(0.05, 0.7, 0.1, 1)` | 进场、页面切换 |
| 标准 `Standard` | `cubic-bezier(0.2, 0, 0, 1)` | 呼吸、常规过渡 |
| 退场 `Exit` | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 退场（更短） |
| 时长 | 120 / 200 / 320 / 480ms；环境动效 ≥ 2400ms | 微交互 / 短 / 中 / 长 |
| 按压弹簧 | 阻尼 0.55、刚度 700 | 按下缩到 97%，松手轻微回弹 |
| 利落弹簧 | 阻尼 0.78、刚度 520 | 开关拇指、分段选择指示块、颜色过渡 |
| 柔和弹簧 | 无回弹、刚度 320 | 布局与位置、进度环 |
| 错峰 | 每项 +40ms，从下方 16dp 浮上 | 首次进入页面（只播一次） |

具体手法：
- **页面切换**：进深共享轴。前进时新页从右侧 1/6 处滑入，旧页缩到 97% 并淡出；返回相反。
- **数字滚动**：只有变化的那几位上下滚（变大往上、变小往下）。
- **舞台**：进度环随任务推进；弧头一颗亮点；环与柔光随任务种类换色（弹簧过渡）。
- **团子**：3.2s 一次呼吸（纵向 +3%）、约 4s 眨一次眼；睡着时冒“z”。干活时呼吸加快、眼睛微微上看。
- **滚动视差**：舞台以 0.4 倍速上移并轻微淡出。
- **骨架屏**：数据未到时斜向闪光。
- **拖拽排序**：按住把手即拖，被拖卡片放大 3% 并投影，其他卡片用弹簧让位；松手位置差用弹簧收回。

**减少动效**：系统「移除动画」（动画时长缩放 = 0）或应用内「减少动效」任一打开，所有过渡瞬时完成，环境动效（呼吸、眨眼、闪光、扫光、心跳扩散）全部停止。

## 6. 触感反馈

走平台 `performHapticFeedback`（系统关掉触感就自动静默），新常量在旧系统上降级：

| 场景 | Android 14+ | 旧系统 |
| --- | --- | --- |
| 托管开 / 关 | `TOGGLE_ON` / `TOGGLE_OFF` | `CONFIRM` / `CLOCK_TICK` |
| 分段选择换一格、拖拽越过一张卡 | `SEGMENT_TICK` | `CLOCK_TICK` |
| 开始 / 结束拖拽 | `GESTURE_START` / `GESTURE_END` | `LONG_PRESS` / `CLOCK_TICK` |
| 保存、读完协议 | `CONFIRM` | `KEYBOARD_TAP` |
| 步进器到头 | `REJECT` | `LONG_PRESS` |

## 7. 无障碍

- 所有图标按钮有内容描述；装饰性图标不朗读。
- 开关、单选、复选都声明角色（Switch / RadioButton / Checkbox）与状态描述。
- 舞台是礼貌播报区（状态变化会被读出），进度环提供进度信息与“还剩 N 分钟”的口语描述。
- 排班卡片提供“上移 / 下移 / 更多操作”自定义操作，不会拖拽也能排序。
- 对比度见第 2 节；字体缩放见第 3 节；减少动效见第 5 节。

## 8. 文案

规则：**简洁、有温度、准确、不自我解释**。标题说“是什么”，说明说“会发生什么”；不写实现原因，不加括号补充，不用感叹号。

| 统一叫法 | 不再使用 |
| --- | --- |
| 托管 / 开启托管 / 托管已暂停 | 自动模式、自动托管（含强保活）、停止托管 |
| 学习、打工、冒险、照顾 | 上课、工作、刷图、喂养 |
| 学习优先 / 打工优先 / 只冒险 / 排班 | 工作优先、只重复冒险、自定义排班 |
| 心跳 | 保活信号 |
| 运行快照 | 诊断数据包 |
| 学累了（今日疲劳） | 降效、疲惫判定 |

## 9. 信息架构

```
首启（仅未同意当前协议时）
 ├─ 开始之前：免费 / 风险自负 / 与腾讯无关
 └─ 许可协议：读到底 → 勾选 → 同意并继续（不同意即退出）

主页「此刻」
 ├─ 舞台：团子 + 进度环 + 状态 + 倒计时 + 心跳行
 ├─ 需要处理的提醒（模块未启用 / 被雇佣 / 失联 / 请求回不来）
 ├─ 托管总开关
 ├─ 怎么干活（四选一）· 练什么（三选一）
 ├─ 宠物数值（随心跳）
 ├─ 今天（次数 + 时长构成）
 └─ 时间线

设置（由注册表生成）
 ├─ 干活：去哪打工 · 刷新打工目录 · 排班 › · 每天最多冒险
 ├─ 提醒：疑似被雇佣时提醒
 ├─ 好友：黑名单 · 白名单 · 刷新好友列表
 ├─ 外观：主题 · 跟随壁纸取色 · 减少动效
 ├─ 诊断与反馈：运行诊断 ›
 └─ 关于：关于 Autoqqpet › · 许可协议 ›
```

## 10. 与后端的约定（界面侧）

界面只通过三条路与后端交互，**动作名、extra 键、prefs 键与旧版逐字一致**：

1. 写模块自己的偏好 `autoqqpet_ui`（`AutoqqpetApplication` 的监听器会把 `Store.SETTINGS_KEYS` 里的键镜像进主存）；
2. 发 `io.github.juwanhwang.autoqqpet.CMD` 广播给 QQ（`setattr / adv / auto / autooff / setwork / joblist / hirealert / schedule / bl / wl / roster / diag`）；
3. 读：`StatusStore`（心跳内存态）、主存 `autoqqpet_store` 的 `daily_json / settings_json / friends_json / diag_json`、`JobCatalogReceiver` 落盘的目录。

### 设置注册表（`ui/settings/SettingsRegistry.kt`）

设置页完全由注册表生成。后端加一个开关，界面只需加一行：

```kotlin
Toggle("foo_on", Group.PLAN, "某某功能", Glyphs.Sparkle, on = "开着时会发生什么。", off = "关着时会发生什么。", action = "setfoo"),
```

- `Toggle` 写 `prefs[key]` 布尔并广播 `action op=on|off`；`Choice` 广播 `op=<值>`；`NumberSetting` 广播 `op=<op> n=<值>`。
- 需要打开前确认的，给 `confirmOn`；只影响外观的，`local = true`（不广播）。
- 新键要在 QQ 重装后也能恢复，需加入 `Store.SETTINGS_KEYS`（后端负责）。

### 心跳字段注册表（`ui/data/HeartbeatFields.kt`）

界面在可见时额外收一份心跳广播的**全部 extra** 并缓存，所以后端往心跳里加字段，界面不改数据层就能拿到；在注册表里加一行就会显示：

```kotlin
Metric("mood", "心情", Glyphs.Smile, max = 100.0),
```

当前界面已经认识、但后端尚未发送的字段（缺失时显示“—”或骨架）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `hunger` | 数字 0–100 | 体力（别名 `stamina`） |
| `clean` | 数字 0–100 | 清洁 |
| `feel` | 数字 0–100 | 心情（别名 `mood`） |
| `gold` | 数字 | 金币 |
| `total` | 数字 | 综合 |
| `pet_name` | 文本 | 宠物名（主页顶部显示） |
| `task_kind` | `study` / `work` / `adventure` | 当前任务种类 |
| `task_name` | 文本 | 当前任务名（课程/岗位/冒险名） |
| `task_start_at` / `task_end_at` | 墙钟毫秒 | 当前任务起止（进度环与倒计时最准的来源） |

没有 `task_*` 时，界面按可信度依次用：当日进度的 `pend.*` → 台账最后一条（时长按分钟取整，最多多算 59 秒）；任务名只取自状态文本 `started:<种类>:<名字>`，对不上就不显示，不猜。
